About SmartFuel

SmartFuel is a serverless fuel price forecasting and alerts system for Spain. It processes data from Spain's Ministry for the Ecological Transition, covering ~12,000 fuel stations nationwide.

Features

  • 📍 Interactive map showing all stations with real-time prices
  • 📈 AI-powered price predictions (UP / DOWN OR STABLE) with confidence scores
  • 🔔 Price alerts — get notified when fuel drops below your target
  • 📊 30-day price history charts per station

How It Works

  1. Data is ingested daily from the Spanish Ministry API
  2. A machine learning model analyzes price trends and external factors
  3. Predictions are generated for each station
  4. Users can subscribe to price alerts via email

Tech Stack

Built with AWS Lambda, Step Functions, DynamoDB, S3, API Gateway, Cognito, and Amplify. Fully serverless with a ~$50 budget.
